# Casa Yoga+Surya

Sitio web del centro de bienestar **Casa Yoga+Surya** — yoga, sonoterapia, terapias
espirituales y artes aéreas en Vuelta de Jorco, Aserrí, Costa Rica.

Un único archivo `index.html` autocontenido (HTML + CSS + JavaScript vanilla, sin
dependencias ni build). Incluye un panel de administración (atajo: `Alt + A`) para
editar textos, fotos, eventos, testimonios, horarios y datos de contacto, con
persistencia en `localStorage`.

## Desarrollo

No requiere instalación. Abre `index.html` directamente en el navegador, o sírvelo
con cualquier servidor estático:

```bash
npx http-server . -p 8123
```

## Despliegue

Sitio estático servido desde la raíz del repositorio (ver `netlify.toml`).
